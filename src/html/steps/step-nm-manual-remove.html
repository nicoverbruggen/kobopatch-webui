If you installed NickelMenu manually from a downloaded ZIP, remove it manually by following these instructions. Some folders may be hidden, so you may need to make hidden files and folders visible.

  1. Connect your Kobo via USB so it appears as a removable drive.
  2. Create an empty file named uninstall inside .adds/nm. This signals to NickelMenu it should remove itself when the device reboots. If the folder is missing, create .adds/nm first.
  3. Safely eject the Kobo, then restart it by long-pressing the power button until it turns off. Press the power button again to turn it back on. NickelMenu will finish removing itself during startup.
  4. If you installed this tool's preset, you can remove .adds/scripts.
  5. If there are no other folders inside .adds besides nm and scripts, open .kobo/Kobo/Kobo eReader.conf and remove the line that starts with ExcludeSyncFolders=.

You can always restart the entire flow by reloading the page, if you want to try again for another configuration or undo the changes that were made.
